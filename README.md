# ABW – Aarna Brick Works

A modern, minimalistic, mobile-first Progressive Web Application (PWA) built for brick makers to effortlessly manage and track:
- 🧱 **Inventory**: Brick production tracking and live stock calculations.
- 💰 **Sales & Payments**: Customer management with 1-click WhatsApp/Call communication, order history, credit/payment tracking, and balance status.
- 👷 **Workers / Labour**: Batch-based labour tracking and salary payouts history.
- ☁️ **Google Drive Sync**: Client-side OAuth 2.0 automatic and manual cloud backups without needing a backend server.
- 📱 **Offline-first PWA**: Full offline caching via Service Worker (`stale-while-revalidate`), installable to home screen with custom icons and manifest.

## Tech Stack
- Pure Vanilla HTML5, CSS3, JavaScript (ES6+)
- Service Worker & Web App Manifest (PWA)
- Google Identity Services (GIS) & Google Drive v3 REST API
- No build tools or node dependencies required.
